# Aproveita Aí

Site informativo de combate ao desperdício de alimentos, com dicas de conservação,
receitas de aproveitamento, uma calculadora de desperdício doméstico e uma lista de
instituições que recebem doações.

Projeto da disciplina de Desenvolvimento Web, alinhado à ODS 12 (meta 12.3).

## Tecnologias

HTML, CSS e JavaScript

## Como rodar

Abra o arquivo `index.html` no navegador ou acesse o link do GitHub Pages.
